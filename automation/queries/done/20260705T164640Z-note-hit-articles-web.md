topic: note 伸びる記事 書き方 分析
noteで伸びている記事（スキ・ビュー・フォロワー増につながった記事）の書き方の傾向を、note公式の発信・書き方解説記事・伸びた記事の分析記事などから調べてください。日本語で回答してください。

調べてほしい観点:
1. タイトル: 伸びる記事のタイトルの型（文字数、数字の使い方、感情語、自分語り系タイトルの強さ）
2. 冒頭（リード文）: 最初の数行で何をしているか。離脱を防ぐ書き出しの型
3. 構成: 見出しの使い方、文章の長さ、改行・空白行の頻度、まとめ方
4. 文体・トーン: noteで好まれる文体（です・ます、語りかけ、自己開示の度合い）。エッセイ系と実用系の違い
5. 画像: アイキャッチ画像の重要度と作り方、本文中の画像の入れ方
6. 拡散の仕組み: noteのアルゴリズム（注目記事、公式マガジン、お題企画）で何が評価されるか

出力は次のセクションに分けてください:
1. タイトルの型
2. 冒頭の型
3. 構成・文体の傾向（エッセイ系と実用系を分けて）
4. 画像の使い方
5. note固有の拡散の仕組み
6. 未確認・断定できない点
各主張には根拠となる記事のURLを付けてください。
