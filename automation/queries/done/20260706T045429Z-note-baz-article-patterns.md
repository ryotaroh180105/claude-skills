topic: note.comで伸びている記事（スキ数・ビュー数・フォロワー増）の書き方の傾向

日本語のnote(note.com)で伸びている記事（スキ数・ビュー数・フォロワー増につながった記事）の
書き方の傾向を調べてください。note公式の書き方ガイド、伸びた記事の分析記事、noteクリエイター
自身の解説記事などを幅広く検索し、実在するURLを出典として明記してください。最低5〜8件程度の
異なる情報源に当たってください。

調べてほしい観点：
1. タイトル：伸びる記事のタイトルの型（文字数の目安、数字の使い方、感情語、自分語り系タイトル
   の強さ、疑問形など）
2. 冒頭（リード文）：最初の数行で何をしているか。離脱を防ぐ書き出しの型（エッセイ系と実用系の
   違い）
3. 構成：見出しの使い方、文章の長さ、改行・空白行の頻度、まとめ方
4. 文体・トーン：noteで好まれる文体（です・ます、語りかけ、自己開示の度合い）
5. 画像：アイキャッチ画像の重要度と作り方（推奨サイズ等）、本文中の画像の入れ方・頻度
6. 拡散の仕組み：noteのアルゴリズム（注目記事、公式マガジン、お題企画、初速の重要性）で何が
   評価されるか

出力は次の形式のMarkdownで、各主張に根拠となる記事のURLを必ず付けてください。URLが確認できない
主張は書かないか「未確認」と明記してください：

1. タイトルの型（実例と出典URL）
2. 冒頭の型（実例と出典URL）
3. 構成・文体の傾向（エッセイ系と実用系を分けて、出典URL）
4. 画像の使い方（出典URL）
5. note固有の拡散の仕組み（出典URL）
6. 未確認・断定できない点（検索で裏付けが取れなかった項目）
