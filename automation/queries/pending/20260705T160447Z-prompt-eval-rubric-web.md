topic: プロンプトエンジニアリング 評価基準 ルーブリック prompt quality evaluation
AI（特に Claude などの LLM コーディングエージェント）への指示・プロンプトの品質を事後評価するための基準・ルーブリックについて、Anthropic 公式のプロンプトエンジニアリングドキュメント・研究記事・note や Zenn の解説記事・海外のプロンプト評価に関する記事を集めて、以下の問いに答えてください。

重要な指示: 要約しすぎないでください。一次情報に近い形が欲しいので、各基準について出典元の文章をなるべくそのまま「」で逐語引用し、出典URLを併記してください。

問い:
1. 良いプロンプトの構成要素として公式・専門家が挙げているものは何か（明確さ、コンテキスト、例示、制約、成功条件など。それぞれの原文定義を引用）
2. プロンプトや AI とのやり取りの質を採点・評価するとき、どんな観点・尺度が提案されているか（ルーブリックの実例があれば構造ごと引用）
3. 人間側の指示の悪さが原因で AI の出力が悪くなる典型パターンとして何が挙げられているか
4. 振り返り（レトロスペクティブ）で AI 活用を改善する取り組みの事例があれば教えてください

出力は日本語で、次のセクションに分けてください:
1. 要点（発見の一覧。各項目に出典URL）
2. 引用可能な原文抜粋（主張ごとに「」で逐語引用 + 出典URL。ここを最も厚くしてください）
3. ルーブリック実例（見つかった評価表・チェックリストを構造ごと引用）
4. 出典リスト
5. 未確認・断定できない点
