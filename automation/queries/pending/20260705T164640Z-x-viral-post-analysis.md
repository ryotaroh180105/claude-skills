分析してほしい観点:
1. フック（1行目）: どんな書き出しが多いか。数字・断定・逆説・問いかけ・自分語りなど、型ごとに実例を挙げる

4. 論理と説得力: どこで根拠を出しているか（体験談・数字・固有名詞）、言い切りとヘッジのバランス
5. なぜ閲覧数・いいねが多いのか: 保存・共有・共感のどれを取りにいっているか、リプライを誘発する仕掛け

出力は次のセクションに分けてください:
1. 伸びたポストの実例（元ポストURL必須、5〜10件）
2. フックの型と実例
3. 言葉遣い・トーンの共通パターン
4. 構成・説得力の共通パターン
5. 伸びる理由の分類（保存・共有・共感・反論誘発）
6. 未確認・断定できない点
