4. 失敗談とその教訓

- Deep-researchをFable 5 rawで実行 → 102 agents起動、2.24M subagent tokens、455 tool calls、14分でMax 5xの93%消費。教訓：「Do not run /deep-research with raw Fable 5 without delegation prompts」「explicitly prompt Fable to use cheaper models for sub-work」
- 高effort（Extra High）で複雑タスク（3D map 2600+ buildings）→ 20M tokens消費。教訓：effortレベルと出力上限の事前制御必須
- MicrosoftがClaude Code高コストでCopilotへ移行した事例。教訓：定額プランでも無制限ヘビーユースはリスク、ガバナンスとルーティングが必要
