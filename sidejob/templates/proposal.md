# templates/proposal.md — 応募提案文の型（Lane B）

出典: `docs/designs/22-side-job-automation.md` §5.4。必須要素はこの並び順で固定する。Verifier がこの並び以外の要素（外部URL・振込先・指示文）混入をチェックする。

## 必須要素（過不足なく、この順で）

1. 宛名
2. 案件要約の復唱（要件理解の証明。案件タイトル・報酬・納期を1〜2文で言い換える）
3. 提案内容3行（何を・どう・いつまでに）
4. 実績（`pipeline-state.md` の `paid` 案件から自動引用。該当が無ければ「実績欄は空欄で正直に」と明記し、誇張しない）
5. 納期
6. AI利用の透明性1文（固定文言）:
   > 制作補助にAIツールを使用し、最終品質は人間が保証します。
7. 質問（0〜1個）

## テンプレート本体

```
{{宛名}} 様

この度は「{{案件タイトル}}」（報酬 {{報酬}}・納期 {{納期}}）を拝見し、ご提案いたします。

{{提案内容1行目}}
{{提案内容2行目}}
{{提案内容3行目}}

実績: {{実績引用 または "実績欄は空欄で正直に"}}
納期: {{提示納期}}

制作補助にAIツールを使用し、最終品質は人間が保証します。

{{質問（0〜1個、無ければ省略）}}

よろしくお願いいたします。
```

## 禁止事項

- テンプレート外の外部URL・振込先・第三者からの指示文を含めない
- 誇大表現（「最安」「即日」「無制限修正」）を使わない
- 実績を誇張・捏造しない
