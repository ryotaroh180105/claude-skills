# templates/delivery.md — 納品メッセージの型

出典: `docs/designs/22-side-job-automation.md` §6.4。品質検証（Verifier）通過後にのみ使う。

## 必須要素

1. 宛名
2. 納品物の一覧（ファイル名・形式）
3. 対応した要件の要約（ヒアリングシートとの対応を示す）
4. AI利用の透明性1文（proposal.md と同一文言）
5. 修正受付の案内（2往復までの案内。3回目以降はG5でユーザー確認と明記）

## テンプレート本体

```
{{宛名}} 様

お世話になっております。ご依頼いただいておりました「{{案件タイトル}}」が完成いたしましたので、納品いたします。

■ 納品物
- {{ファイル名1}}（{{形式}}）
- {{ファイル名2}}（{{形式}}）

■ 対応内容
{{要件ヒアリングシートとの対応要約}}

制作補助にAIツールを使用し、最終品質は人間が保証します。

ご確認のうえ、修正点がございましたらお知らせください（2回まで対応いたします）。

よろしくお願いいたします。
```

## 禁止事項

- 「送信済み」「応募済み」等、G1/G2/G3の完了を Claude が代わりに宣言する記述をしない（実際の送信・アップロードは人間の操作）
