# templates/listing.md — 出品サービス文の型（Lane A/C）

出典: `docs/designs/22-side-job-automation.md` §6.6。ココナラ出品・BOOTH/Gumroadテンプレ販売の出品文で共通の型。

## 必須要素

1. サービスタイトル（何を作るか一言）
2. 提供内容（箇条書き3〜5点。納品形式・修正回数・納期を明記）
3. 価格（`sidejob/config.md` の単価下限を下回らない。ココナラ出品の初期価格はユーザー確認事項 — 設計書§12-5）
4. AI利用の明記（1文。ココナラは規約上必須）:
   > 制作にAIツールを活用しています。最終品質・納品物の確認は人間が行います。
5. 対応可能な依頼・不可な依頼（電話・会議必須の依頼は不可、とG2/除外条件に整合させる）

## テンプレート本体

```
【{{サービスタイトル}}】

■ 提供内容
- {{内容1}}
- {{内容2}}
- {{内容3}}

■ 価格: {{価格}}円〜
■ 納期: {{標準納期}}
■ 修正: {{修正回数}}回まで対応

制作にAIツールを活用しています。最終品質・納品物の確認は人間が行います。

■ ご注意
- お電話・ビデオ通話でのお打ち合わせは承っておりません（テキストでのやり取りのみ）
- AI生成イラスト・画像を主成果物とする出品はしておりません（テキスト・コード・テンプレ制作のみ）
```

## 禁止事項

- AI生成イラスト・画像を主成果物として出品しない（ココナラ規約禁止。設計書§2.2）
- 誇大表現（「最安」「即日」「無制限修正」）を使わない
