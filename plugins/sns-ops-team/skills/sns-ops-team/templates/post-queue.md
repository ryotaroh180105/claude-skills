## フォーマット定義

| 列 | 内容 | ルール |
|---|---|---|
| id | 投稿の一意な連番 | 3桁ゼロ埋め（001, 002, ...）。既存の最大値から連番を継続。欠番は再利用しない |
| platform | 投稿先 | `x` / `instagram` / `tiktok` のいずれか小文字 |
| 予定日時 | 投稿予定 | `YYYY-MM-DD HH:MM`（JST）。未投稿行どうしで重複させない |
| 本文 | 投稿する文章そのもの | セル内改行は `<br>`、縦棒は `\|` にエスケープ。ハッシュタグも本文に含める |
| メディア | 添付画像・動画 | ファイルパスまたはURL。無ければ `-` |
| ステータス | 行の状態 | `draft` / `approved` / `posted` のみ（下記の遷移ルール参照） |

### ステータス遷移ルール（誰が変えてよいか）

- `draft` → `approved`: **Ryo（人間）だけ**が変更する。これが承認行為。
- `approved` → `posted`: **sns-auto-posting スキルだけ**が、投稿成功後に変更する。
- sns-ops-team は常に `draft` で追記し、既存行のステータスには触らない。
- 没にする場合: Ryo が行ごと削除するか、修正指示を出して本文を直させ `draft` のまま残す。
