# 記入例: 英単語学習アプリ（仮称: TangoBattle） ビジネス運用面シート

実地適用テスト（test-log.md 2周目）で生成した実例。粒度の基準: 全項目1〜2行・仮置きは正直に仮置きと書く。

- 一文価値提案: 大学の友達同士が、市販の単語帳アプリを別々に使わずに、同じ単語セットをクイズで競いながら覚えられる
- 想定ユーザー（固有名詞3人）: 自分（TOEIC対策）、サークル後輩D（TOEIC単語で挫折中）、インターン同期M（留学準備）※公開版のため属性+イニシャル
- 代替手段と乗り換え理由（1点）: 代替 = mikan/Anki/Quizlet/紙の単語帳/ChatGPT直接。乗り換え理由は現状 No →（仮置き・調査中）。x_search で不満の種を調査し、リリース前に見直す
- 導入: 手順数 3 / 所要 3分 / 前提条件: なし（ブラウザのみ・アカウント不要でゲスト開始）
- 保守: 予算 週30分 / 壊れる要因: 無料ホスティングの仕様変更・単語データ取得元の変更 / 廃止基準: 予算2回連続超過 or ユーザー0が2ヶ月
- 運用: 定常作業: なし（静的+サーバレス、外部API不使用） / 失敗通知経路: ホスティング障害のメール通知1本 / 1利用あたりコスト: ほぼ0円（無料枠内）
- 収益/回収: 無料。回収は G3（就活で話せる実績）+ 週次学習データの記事ネタ化
- 配布チャネルと最初の10ユーザー（到達期限: 公開後2週）: サークルLINEグループ（約20人）に直接URL。X告知は10人到達後
- 記録する指標: 新規アクセス人数 / 7日内再訪（ホスティング標準ログ）/ 紹介された数（LINEで手動カウント）＋自分の週あたり学習回数
- 意図的に無視すること: アカウント・課金・多言語 / 監視ダッシュボード
- 悪魔の代弁者: 指摘3件（①mikanで足りる ②友達同士でも続かないのは競争でなく通知の問題 ③単語データの用意が面倒）→処理: ①は乗り換え理由の仮置き調査に含める、②は初回10人の再訪データで判定、③は市販単語帳準拠のプリセット同梱で解消
