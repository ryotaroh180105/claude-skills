# 記入例: 英単語学習アプリ（仮称: TangoBattle） ビジネス運用面シート

v2.0（実シグナルゲート）に合わせて改訂。経路: ファストパス（半日でコアデモが作れたため）。
粒度の基準: 全項目1〜2行・仮置きは正直に仮置きと書く。

- 価値提案: 大学の友達同士が、市販の単語帳アプリを別々に使わずに、同じ単語セットをクイズで競いながら覚えられる
- 実在ユーザー3人: 自分（TOEIC対策・毎朝の通学中に単語アプリを開く）、サークル後輩D（TOEIC単語で挫折中・忙しくて続かない）、インターン同期M（留学準備・友達と競争したいと発言）※公開版のため属性+イニシャル
- 実シグナル: Dから「LINEで送られたら使う」と返信（7/6）、Mが試作版に3回アクセス（ホスティングログ、7/6-7/7）
- 導入: 手順数 3 / 所要 3分 / 前提条件: なし（ブラウザのみ・アカウント不要でゲスト開始）
- 保守運用: 週30分 / 壊れる要因: 無料ホスティングの仕様変更・単語データ取得元の変更 / 失敗通知経路: ホスティング障害のメール通知1本 / 廃止基準: 予算2回連続超過 or ユーザー0が2ヶ月
- 配布: サークルLINEグループ（約20人）に直接URL、X告知は10人到達後 / 最初の10人 / 到達期限 公開後2週
- 収益/回収: 無料。回収は G3（就活で話せる実績）+ 週次学習データの記事ネタ化
- 指標: 新規アクセス人数 / 7日内再訪（ホスティング標準ログ）/ 紹介された数（LINEで手動カウント）
- 意図的に無視すること: アカウント・課金・多言語 / 監視ダッシュボード / 代替手段からの乗り換え理由の精緻化（実シグナルで代替済みのため深追いしない）
- 悪魔の代弁者: 指摘3件（①mikanで足りる ②友達同士でも続かないのは競争でなく通知の問題 ③単語データの用意が面倒）→処理: ①は実シグナル（Dの返信）で実証済みと判断、②は初回10人の再訪データで判定、③は市販単語帳準拠のプリセット同梱で解消
