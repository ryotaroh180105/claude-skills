## KPI判断表（kpi-log.md 末尾にも同一内容を転記する）

週次で見るのは kpi-log.md の9列。判断は上から順に最初に該当した行を適用する。

| 条件 | 判断 |
|---|---|
| 作業分が2週連続で <週次作業予算>分 を超過 | 縮小（投稿数を減らす。それでも超過なら撤退検討） |
| 直近4週の note誘導クリック合計 < 10 | 調整（集客側の問題。ポストのCTA・テーマを sns-ops-team の振り返りで変更） |
| 直近4週の note誘導クリック合計 ≥ 10 かつ リンククリック合計 = 0 | 調整（記事側の問題。リンク位置・商品選定を変更） |
| 開始から12週経過で 発生件数累計 = 0 | 撤退検討（ジャンルまたは受け皿を変えて再スタートするか、凍結するかをユーザーに提示） |
| 開始から24週経過で 確定額累計 = 0円 | 撤退（Phase 1 構造を凍結し、学びを biz-ops-guard の定期レビュー形式でシートに追記して閉じる） |
| 上記いずれにも該当しない | 継続 |

判断表の数値（10クリック/12週/24週/週次作業予算）は実装時に変えない。運用4週ごとのレビューで
ユーザーが改訂する場合のみ変更し、改訂記録は kpi-log.md 末尾に日付つきで残す。

## 規約・数値に関する注記（断定禁止）

- 数値（報酬率・料率・審査日数）は断定せず「要調査」と書き、hermes-relay（engine: notebooklm + topic）の
  調査結果を「調査日」付きで反映する。
- 規約は「X/note/ASPの規約では〜」と断定形で書かない。「YYYY-MM時点の調査では〜。運用開始時に再確認」の形式に統一する。
- 例（要調査プレースホルダ。実装時・運用開始時に埋める）:
  - note のアフィリエイトリンク可否と条件: 要調査（調査日: -）
  - X の外部リンク・アフィリエイト関連の現行規約とリーチへの影響: 要調査（調査日: -）
  - ASP各社の審査条件・PR表記要件の比較: 要調査（調査日: -）
