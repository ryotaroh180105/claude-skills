## フォーマット定義

| 列 | 内容 | 取得元 |
|---|---|---|
| 週 | ISO週番号 | 例: 2026-W30 |
| 投稿数 | 当該週のX投稿数 | post-queue.md の posted 行を集計 |
| note誘導クリック | Xポストからnoteへのリンククリック数 | X アナリティクス |
| note PV | note記事のページビュー | note ダッシュボード |
| リンククリック | アフィリエイトリンクのクリック数 | ASP管理画面 |
| 発生件数 | 成果発生件数 | ASP管理画面 |
| 確定件数 | 成果確定件数 | ASP管理画面 |
| 確定額(円) | 確定報酬額 | ASP管理画面 |
| 作業分 | 当該週の制作〜転記作業時間（分） | 自己申告 |
| 判断 | 継続/調整/縮小/撤退検討/撤退/保留 | funnel-config.md のKPI判断表を適用した結果 |
