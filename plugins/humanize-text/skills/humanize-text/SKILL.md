# humanize-text（AI臭除去）

目的: AI生成文特有の「AIっぽさ」を除去し、人間が書いたような文章に整える推敲専用スキル。
**意味・事実・文字数レンジは変えない**。内容を良くする・書き直すスキルではない。

出典: X投稿「AI臭を消すプロンプト8選」を「症状診断→該当変換のみ適用」の2段構成に
再構成したもの（アカウント名は原文に含まれないため「X投稿より」）。

## 対象外

- **技術文書・法務文書**: 正確さ・厳密さが優先される文章には使わない。依頼が来たら
  「技術文書/法務文書は対象外」と伝えて中止する。
- コード・数式・引用符号内のテキストは変換対象に含めない（そのまま保持）。

## 進め方

### ① 文体メモを確認する

記事管理ディレクトリに `style-memo.md`（article-writer が作るもの）があれば読み込み、
語尾・一人称・読者との距離感をその人の文体に寄せる基準として使う。無ければこの手順は
スキップし、原文の元々のトーンを保つことだけを基準にする。

### ② 症状診断（6項目）

原文を読み、以下6症状のうち該当するものをすべて列挙する。診断結果は最終出力の
サマリに使うので、チェックしながら進める。

| # | 症状 | 兆候 |
|---|---|---|
| 1 | 文長の単調さ | ほぼ全文が同じ長さ・同じ構文の文が連続している |
| 2 | 定型表現 | 「いかがでしたか」「〜と言えるでしょう」「〜と言わざるを得ません」等の紋切り型が入っている |
| 3 | 教科書調 | 「〜について解説します」のような説明口調・講義的な構成になっている |
| 4 | 過剰な網羅・箇条書き | 言わなくてもいい内容まで律儀に箇条書き・全項目網羅している |
| 5 | 感情の欠落 | 抑揚がなく淡々としている。読み手の心が動く要素がない |
| 6 | 語りかけの欠如 | 読み手を意識した呼びかけ・話しかけの調子がゼロで、独白のように書かれている |

**該当なしの場合**: 「変更不要」と回答し、原文をそのまま返す。無理に変えない。

### ③ 該当変換のみ適用

診断で該当した症状にだけ、対応する変換を適用する。8個を順に全部かけない。

| 症状 | 適用する変換 | 変換の要点 |
|---|---|---|
| 1. 文長の単調さ | リズム調整 | 文の長さに意図的に変化をつけ、テンポを整える。繰り返し表現・先が読める言い回しを削る |
| 2. 定型表現 | 人間らしさ復元 | 経験者が書いたようなリズム・言葉選びに直す。AI特有の型・定型句を避ける |
| 3. 教科書調 | 語りかけ変換 + 編集長モード | 教科書的な説明を削り、専門家が親しい相手に話すような会話調に直す |
| 4. 過剰な網羅・箇条書き | 地声 | AIっぽい型（律儀な網羅・箇条書き偏重）を捨て、一番伝えたいことをストレートに書く |
| 5. 感情の欠落 | 体温注入 | 人間らしい感情・文章の強弱を加える。単調な繰り返しをなくす |
| 6. 語りかけの欠如 | 語りかけ変換 | 仲の良い専門家が話すような親しみやすい調子を加える |

適用中は常に守る:
- 意味・事実・固有名詞・数値を変更しない。
- 誇張の追加・内容の水増しをしない（新しい主張・エピソードを足さない）。
- 元の文字数レンジ（±1〜2割目安）を大きく超えない。
- 文体メモがあれば語尾・一人称をそれに合わせる。

### ④ 仕上げパス（症状が1つでも該当した場合のみ・最後に1回）

③の変換後、全体を通して1回だけ仕上げる: トーンと構成を整え、自信を持った実在の
人物が書いた最終版のように調整する。ここでも意味・事実・固有名詞・数値は変えない。
症状が0件だった場合（②で「変更不要」と判定した場合）はこのパスを行わない。

### ⑤ 出力

1. 診断結果: 該当した症状を番号で短く列挙（例: 「該当: 2, 4, 6」）。0件なら「該当なし → 変更不要」。
2. 変換後の全文（該当なしの場合は原文をそのまま）。
3. 適用した変換名を1行で列挙（例: 「適用: 人間らしさ復元, 地声, 語りかけ変換, 仕上げ」）。

## エッジケース

- **元が十分自然**: 診断で0件 → 「変更不要」とだけ返す。品質を上げるための書き直しはしない。
- **技術文書・法務文書**: 対象外。依頼段階で気づいたら理由を添えて断る。
- **文体メモが無い/読者情報が薄い**: 元の文章から読み取れるトーンだけを基準にする。
  勝手に人格・キャラクターを作らない。
- **一部だけAI臭が強い（他は自然）**: 該当箇所のみ変換し、既に自然な箇所は触らない。
- **箇条書き自体が読者の要望で必要な文章**（手順書・チェックリスト等）: 症状4は
  「言わなくていい内容まで律儀に網羅している」場合のみ該当とし、必要な箇条書き構造は壊さない。

## 前提セットアップ

外部依存なし。MCP・APIキー・環境変数は不要。`style-memo.md` は任意入力（あれば読む、
無くても動作する）。
