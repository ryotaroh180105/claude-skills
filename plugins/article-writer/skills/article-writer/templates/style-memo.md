# 文体メモ（style-memo）

Ryo の note 記事の文体を蓄積するファイル。article-writer スキルが執筆・推敲時に必ず参照する。
記事を書くたびにフィードバックを反映して更新する。**確定していない項目には `【仮】` を付ける。**

最終更新: ____-__-__（記事: ____________________）

## 1. 基本設定

| 項目 | 内容 |
|---|---|
| 一人称 | 例: 僕 |
| 文末表現 | 例: です・ます調。ただし強調したい一文だけ体言止め可 |
| 読者への呼びかけ | 例: 「あなた」は使わず「〜な人」と書く |
| 全体の温度感 | 例: 柔らかめ・等身大。上から目線にしない |

## 2. 文末表現の傾向

- よく使う語尾: （例: 〜です / 〜と思います / 〜でした）
- 避けたい語尾: （例: 〜ですね の多用 / 〜だろう）
- 語尾のバリエーション方針: （例: 同じ語尾は2連続まで。3連続したら体言止めか疑問形を挟む）

## 3. 漢字とひらがなの開き方

| 開く（ひらがな） | 閉じる（漢字） |
|---|---|
| 例: できる、いろいろ、ぜひ、〜のとき | 例: 経験、実際、結果 |

- 迷ったときの方針: （例: 副詞・補助動詞は開く。名詞は閉じる）

## 4. 絵文字・記号の使用

| 項目 | 方針 |
|---|---|
| 絵文字 | 例: 使わない / 見出しにのみ1個まで |
| 「！」 | 例: 1記事に2〜3回まで |
| 「…」「（笑）」 | 例: 使わない |
| 太字 | 例: 1見出しにつき1箇所まで。結論の文だけ |
| 箇条書き | 例: 3項目以上並ぶときだけ使う |

## 5. 段落の長さ・リズム

- 1段落の目安: （例: 2〜4文。スマホで4〜6行以内）
- 改行の癖: （例: 話が切り替わる前に1行空ける）
- 1文の長さ: （例: 60字以内を目安に短く切る）

## 6. NG表現

使わない・使いたくない表現のリスト。推敲時に必ずチェックする。

- 例: 「〜させていただく」の多用
- 例: 「絶対」「必ず」などの根拠なき断定
- 例: 「いかがでしたか？」で締める
