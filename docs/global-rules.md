# グローバルルール移植キット

`MISTAKES.md`（ミス再発防止DB）と「ユーザー操作依頼の説明義務」を、
claude-skills リポジトリ外のあらゆる環境（claude.ai / ローカル Claude Code /
他リポジトリのリモートセッション）に適用するための手順書。

**ルールの原本はこのリポジトリ**（`MISTAKES.md` と `CLAUDE.md` の該当節）。
他環境へは下の貼り付けブロックで配布し、文言を変えたらここも更新する。

## 環境ごとの適用マトリクス

| 環境 | ルールの載せ場所 | ミス記録の方法 | 自動注入 |
|---|---|---|---|
| このリポジトリのセッション（ローカル/リモート） | `CLAUDE.md`（適用済み） | MISTAKES.md に直接 push | フックで自動（適用済み） |
| ローカル Claude Code（全プロジェクト共通） | `~/.claude/CLAUDE.md` | ローカル clone 経由で push | `~/.claude/settings.json` のフック（下記） |
| 他リポジトリのリモートセッション | そのリポジトリの `CLAUDE.md` | push 不可なら「M-登録依頼」を出力 | 不可（CLAUDE.md 指示のみ） |
| claude.ai（チャット） | 設定 > プロファイル > 個人設定 | 「M-登録依頼」を出力 → ユーザーが後で登録 | 不可（個人設定は毎回読まれる） |

## 貼り付けブロック A: `~/.claude/CLAUDE.md` / 他リポジトリの `CLAUDE.md` 用

```markdown
## 常時適用: ミス再発防止 & 操作依頼の説明義務（原本: ryotaroh180105/claude-skills）

- Claude のミス・エラーが発覚したら、claude-skills リポジトリの `MISTAKES.md` に
  記録する（形式は同ファイル冒頭の運用ルールが正）。push できない環境では、
  「M-登録依頼」として 事象/根本原因/再発防止ルール案 を出力し、ユーザーが後で登録する。
- `MISTAKES.md` の「再発防止ルール」に反する行動を取らない。フック未設定の環境では
  作業開始前に同ファイルを読む（読めない環境では既知ルールの範囲で従う）。
- ユーザーに操作・行動を依頼する時は、依頼の前に必ず (1)意図 (2)具体的な内容
  (3)成功の確認方法 を示す。Claude 自身で実行できない場合は理由も添える。
  説明なしの「〜してください」は禁止。
```

## 貼り付けブロック B: claude.ai の個人設定用（短縮版）

```text
・あなた(Claude)のミスや誤答が会話中に発覚したら、その場で「M-登録依頼」として
  事象・根本原因・再発防止ルール案を箇条書きで出力する（私が claude-skills リポジトリの
  MISTAKES.md に登録する運用のため）。
・私に何か操作や行動を依頼する時は、必ず (1)意図 (2)具体的な内容 (3)成功の確認方法 を
  先に説明する。説明なしの「〜してください」は禁止。
```

## ローカル Claude Code の自動注入フック（`~/.claude/settings.json`）

claude-skills のローカル clone がある前提。`<CLONE_PATH>` を実パスに置換:

```json
{
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "sed -n '/<!-- rules:start -->/,/<!-- rules:end -->/p' <CLONE_PATH>/MISTAKES.md"
          }
        ]
      }
    ]
  }
}
```

- 既に `hooks` キーがある場合は `SessionStart` 配列にマージする。
- 最新ルールを常に反映したい場合はコマンド先頭に
  `git -C <CLONE_PATH> pull --ff-only -q 2>/dev/null;` を足す（オフライン時も動くよう `;` 区切り）。
- 確認方法: 任意のプロジェクトで新セッションを開始し、開始時メッセージに
  「再発防止ルール（毎セッション自動読み込み）」が出れば成功。

## 「M-登録依頼」の書式（push できない環境の出力）

```markdown
### M-登録依頼: <タイトル>
- 事象:
- 根本原因:
- 再発防止ルール案（1行）:
```

ユーザーはこれを claude-skills のセッションに貼り、`MISTAKES.md` へ正式登録する。
