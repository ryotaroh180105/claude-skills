# スキル要件定義書

全スキルの要件定義。作成前の仕様であり、壁打ちで随時更新する（このファイルが最新の正）。

目的タグ:
- **G1** = インターンの仕事の効率・質を上げる（早くコンサル側にアサインされる）
- **G2** = 個人開発・副業で稼ぐ（SNS運用 + ウェブ系）
- **G3** = 就活で話せるエピソード・実績を作る
- **基盤** = 他のスキル・作業の土台

共通の完了条件（全スキル）:
- `validate_skills.py` を通過し、marketplace 経由でインストールできる
- 外部依存があるスキルは、SKILL.md の「前提セットアップ」に必要な MCP / API キー / 環境変数が表で明記され、**Ryo が値を入力すれば即動く**こと（未設定時はスキル自身がユーザーに確認する）
- 作成後に壁打ちを1回以上行い、フィードバックを反映して version を上げる

## Tier1: 基盤スキル

### requirements-definition 【基盤 / G1】
- **概要**: 曖昧な依頼・アイデアから構造化された要件定義書を作る思考フレームワークスキル。
- **主要機能**: ①イシュー特定（解く価値×答えを出せる度合い）②MECE分解 ③ピラミッド構造化。ヒアリング質問リストと要件定義書テンプレート（背景/イシュー/ゴール・KPI/スコープ/機能・非機能要件/MoSCoW/リスク）を提供。
- **外部依存**: なし
- **備考**: 他の全スキルの要件定義にもこのスキルを使う（ドッグフーディング）。

### work-approach-playbook 【基盤 / G1】
- **概要**: 仕事の着手前・進行中・完了時の型。依頼主がいる仕事（インターン・副業）想定。
- **主要機能**: 作業前チェックリスト（目的/完了定義/制約/優先度/アウトプットイメージすり合わせ/質問洗い出し）、報連相の型（15分ルール）、完了報告と振り返りフォーマット。
- **外部依存**: なし

### skill-creator 【基盤】
- **概要**: このリポジトリでスキルを新規作成・改善するメタスキル。
- **主要機能**: 新規作成ワークフロー（ディレクトリ→SKILL.md→marketplace.json→validate→push→**導入確認まで**）、良いSKILL.mdの書き方（descriptionのトリガー設計・前提セットアップ節）、練度向上ワークフロー（壁打ちフィードバック→SKILL.md改訂→version up）、ROADMAPステータス更新。
- **外部依存**: なし

### task-management 【基盤 / G1 / G2】
- **概要**: インターン・副業・学習のタスクを Markdown（TODO.md）で管理。
- **主要機能**: 受付→2時間粒度に分解→緊急度×重要度で優先順位→今日やる3つ→進捗更新→週次振り返り。`## Today / This Week / Backlog / Done` ボード形式。
- **外部依存**: なし（GitHub Issues 連携はオプション、GitHub MCP 接続時のみ）

## Tier2: 高難易度スキル（Fable無料期間中に実装）

### hermes-agent-setup 【基盤 / G2】
- **概要**: Hermes Agent + MCP + Grok/X Search を組み合わせた情報収集基盤のセットアップと運用。
- **主要機能**: ①必要コンポーネントの導入手順 ②MCP サーバー設定の生成 ③収集クエリのテンプレート（仕事に活かせそうなスキル/エージェント事例の収集）④収集結果を ROADMAP の候補リストに整形して追記。
- **外部依存**: xAI (Grok) API キー、X API（または Grok の X Search で代替）、Hermes Agent 本体。**キー入力欄と設定ファイル雛形を用意し、値を入れれば動く状態にする。**
- **備考**: twitter-intel / github-trends と併せて「収集→実装パイプライン」の中核。

### voicememo-pipeline 【G1】
- **概要**: 録音ファイル→文字起こし→議事録+フィードバック生成→Google Drive 保存 / Slack 送信の自動パイプライン。
- **主要機能**: ①音声ファイル受領（ローカル/Drive）②文字起こし（Whisper API 等）③議事録整形（決定事項/TODO/期限）④会話へのフィードバック生成（話し方・質問の質等）⑤Drive アップロード ⑥Slack 通知。
- **外部依存**: 文字起こし API キー（OpenAI Whisper 推奨、代替: Gemini）、Google Drive（MCP 接続済みなら流用）、Slack（Webhook URL または MCP）。
- **完了条件**: サンプル音声で end-to-end が通ること（キー入力後）。

### sns-ops-team 【G2】
- **概要**: SNS運用をマルチエージェント（企画/リサーチ/執筆/レビュー/スケジュール管理）で回すオーケストレーションスキル。
- **主要機能**: ①アカウント戦略の読み込み（ターゲット/トーン/NG）②ネタ出しエージェント ③執筆エージェント ④レビューエージェント（炎上リスク・トーンチェック）⑤投稿キュー生成。投稿実行は sns-auto-posting に委譲。
- **外部依存**: 投稿実行時のみ sns-auto-posting 側の API。運用戦略ファイル（`sns-strategy.md`）を初回に一緒に作る。

### model-switcher 【基盤】
- **概要**: タスク種別に応じて使うモデル（Fable/Opus/Sonnet/Haiku）を選択・切り替える判断基準と設定手順。
- **主要機能**: ①タスク分類（設計・難コード=上位モデル / 定型・大量処理=Haiku 等）②Claude Code での切替方法（/model、settings、サブエージェントの model 指定）③コスト目安表 ④無料期間終了後（7/7以降）の推奨構成。
- **外部依存**: なし

### github-trends 【基盤 / G3】
- **概要**: GitHub トレンドやスキル系リポジトリを定期取得し、仕事に活かせそうなものを候補リスト化。採択判断は必ず Ryo が行う。
- **主要機能**: ①トレンド/検索クエリで収集（GitHub MCP / WebFetch）②「スキル化できそうか」の観点で要約・スコアリング ③ROADMAP.md の候補リストに追記 ④定期実行の設定手順（トリガー/cron）。
- **外部依存**: GitHub MCP（接続済み）。定期実行はセッションのトリガー機能。

### code-review-adr 【G1】
- **概要**: コードレビューと ADR（Architecture Decision Record）作成を一体で行う。
- **主要機能**: ①レビュー観点チェックリスト（正しさ/可読性/セキュリティ/性能）②指摘フォーマット（重要度付き）③アーキテクチャ上の判断を検出したら ADR テンプレート（背景/選択肢/決定/結果）で `docs/adr/` に記録。
- **外部依存**: なし（GitHub MCP があれば PR に直接コメント可）

### pr-review 【G1】
- **概要**: GitHub PR のレビュー実行スキル。インターンでのレビュー業務・自分のPRのセルフレビューに使う。
- **主要機能**: ①PR の diff・関連コード・CI 状態の取得 ②観点別レビュー（バグ/設計/テスト漏れ）③レビューコメントの下書き生成（そのまま投稿 or Ryo が確認して投稿を選択）。
- **外部依存**: GitHub MCP（接続済み）

## Tier3: 目的直結スキル

### lp-builder 【G2】
- **概要**: LP（ランディングページ）作成の副業用スキル。ヒアリングから納品まで。
- **主要機能**: ①クライアントヒアリングシート ②構成設計（AIDA/PASONA）③コピーライティング ④HTML/CSS/JS 実装（レスポンシブ・単一ファイル納品可）⑤デプロイ手順（Vercel/Netlify 等）⑥修正対応の型。
- **外部依存**: なし（デプロイ先アカウントは案件ごと）

### article-writer 【G2 / G3】
- **概要**: note 記事の企画・執筆・推敲スキル。
- **主要機能**: ①ネタ→切り口設計（読者・提供価値）②タイトル案複数 ③構成→本文執筆（Ryoの文体を学習する文体メモ運用）④推敲チェックリスト ⑤ハッシュタグ・導線提案。投稿は手動。
- **外部依存**: なし

### owned-media 【G2】
- **概要**: オウンドメディアの SEO 記事作成スキル。
- **主要機能**: ①キーワード選定（検索意図分析、WebSearch 使用）②競合上位記事の構成分析 ③アウトライン→執筆 ④E-E-A-T・内部リンク・メタ情報のチェックリスト。
- **外部依存**: WebSearch（内蔵）。順位計測ツール連携は将来拡張。

### sns-auto-posting 【G2】
- **概要**: Twitter/X・Instagram・TikTok への投稿を自動化する実行系スキル。
- **主要機能**: ①投稿キュー（sns-ops-team の出力）読み込み ②プラットフォーム別フォーマット変換 ③API 経由で投稿 ④結果ログとリトライ。
- **外部依存**: X API キー、Meta Graph API（Instagram）、TikTok API または Buffer 等の仲介サービス。**プラットフォームごとに「キー未設定ならスキップして手動投稿用テキストを出力」のフォールバックを必須にする。**

### twitter-intel 【基盤 / G2】
- **概要**: X（Twitter）から仕事に活かせる情報（スキルネタ・技術トレンド・SNS運用の勝ちパターン）を収集・要約。
- **主要機能**: ①テーマ別収集クエリ ②収集（X API / Grok X Search / agent-reach のいずれか、利用可能なものを自動選択）③要約とスキル化候補の抽出 ④ROADMAP 候補リストへの追記。
- **外部依存**: X API キー or xAI API キー or agent-reach セットアップ。いずれか1つで動く設計。

### testcase-usecase 【G1】
- **概要**: 仕様・要件からユースケースとテストケースを網羅的に洗い出す。
- **主要機能**: ①仕様の読み込みと不明点リスト ②アクター×ゴールでユースケース列挙 ③正常系/異常系/境界値のテストケース展開（表形式）④優先度付け ⑤Excel/スプレッドシート貼り付け用 TSV 出力。
- **外部依存**: なし

### document-creation 【G1】
- **概要**: インターン業務の書類（議事録・提案書・報告書・依頼文）を型で素早く作る。
- **主要機能**: 書類種別ごとのテンプレートとヒアリング項目、結論ファーストの構成、社外向けトーン調整、Google Drive 保存（オプション）。
- **外部依存**: なし（Drive 保存は MCP 接続時のみ）

### pickup-automation 【G1】
- **概要**: 情報源から条件に合うものを定期的に抽出・整形するピックアップ業務の自動化。
- **主要機能**: ①対象情報源と抽出条件のヒアリング（初回壁打ちで確定）②収集→フィルタ→整形のパイプライン ③定期実行設定。
- **外部依存**: 情報源による（要壁打ち）。**要件が最も未確定なスキル。v1 は汎用フレームで作り、壁打ちでインターン固有業務に合わせて具体化する。**

### consulting-quiz 【G1 / G3】
- **概要**: コンサル・営業知識のクイズ出題・採点・弱点管理。
- **主要機能**: ①分野別出題（ロジカルシンキング/フレームワーク/会計/営業手法）②ケース面接ミニ問題 ③採点と解説 ④間違い記録（`quiz-log.md`）と弱点復習モード。
- **外部依存**: なし

### aws-exam-practice 【学習 / G3】
- **概要**: AWS 認定試験（まず SAA 想定）の模試スキル。
- **主要機能**: ①本番形式の出題（4択・シナリオ問題）②採点と分野別正答率 ③解説（なぜ他の選択肢が誤りか）④弱点分野の集中出題 ⑤学習ログ（`aws-study-log.md`）。
- **外部依存**: なし
